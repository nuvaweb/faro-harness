# faro/gestion/

Direccion del trabajo: el "como se dirige" el proyecto, no el producto documental.

Aqui van los cambios (spec-driven, en `cambios/`), el reporting (`reporting/`), las
decisiones, los riesgos y los KPIs.

El producto documental (brief, funcional, analisis) vive en `faro/documentos/`.
