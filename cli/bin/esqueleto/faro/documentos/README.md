# faro/documentos/

Documentacion CONTROLADA: prosa con cabecera (`doc_id`, version, estado). Aqui viven
brief, funcional, analisis (ANA), ADR y demas, ordenados en subcarpeta tematica y con
nombre `<doc_id>-<slug>.md`.

El control lo da la cabecera; la aprobacion es el merge a `main`.

NO va aqui codigo ni notebooks (`faro/notebooks/`), datos ni brutos (`faro/fuentes/`),
ni utilidades (`scripts/`).
