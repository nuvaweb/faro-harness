# Proyecto FARO

Repo de trabajo gobernado por el harness FARO: documentación, gestión y, si hace falta, código en un mismo sitio.

## Empezar

Abre este repo con Claude Code. El plugin `faro` se instala solo y `/faro:iniciar` te guía para definir el trabajo.

## Estructura

- `faro/documentos/`: documentación controlada.
- `faro/gestion/`: cambios, reporting, riesgos y KPIs.
- `faro/fuentes/`: material de partida.
- `faro/flujos/`, `faro/notebooks/` y `scripts/`: capa técnica.
- `faro/borrador/`: pruebas desechables, sin versionar.
