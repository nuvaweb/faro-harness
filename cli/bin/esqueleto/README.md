# Proyecto FARO

Repo de trabajo gobernado por el harness FARO: documentación, gestión y, si hace falta, código en un mismo sitio.

## Empezar

Abre este repo con Claude Code. El plugin `faro` se instala solo y `/faro:iniciar` te guía para definir el trabajo.

## Estructura

- `documentos/`: documentación controlada.
- `gestion/`: cambios, reporting, riesgos y KPIs.
- `fuentes/`: material de partida.
- `flujos/`, `notebooks/` y `scripts/`: capa técnica.
- `borrador/`: pruebas desechables, sin versionar.
